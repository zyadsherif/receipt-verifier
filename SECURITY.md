# Security policy

## Supported versions

Security fixes are applied to the latest published minor version.

## Reporting

Do not open a public issue for a vulnerability or include real payment evidence. Use GitHub's private vulnerability reporting for `zyadsherif/receipt-verifier`. Include a minimal synthetic reproduction, impact, and suggested mitigation when possible.

This package is decision support, not authoritative proof of settlement. Reports that demonstrate a known-negative receipt receiving `pass`, replay-protection bypass, secret disclosure, or unsafe image handling are especially important.
