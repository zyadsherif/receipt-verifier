# Code of conduct

We are committed to a welcoming, harassment-free project for everyone. Be respectful, assume good intent while examining evidence, keep criticism technical and constructive, and protect the privacy of people represented in payment data.

Unacceptable behavior includes harassment, discrimination, threats, publishing private information, sharing real receipts without consent, or deliberately weakening security controls without transparent discussion.

Project maintainers may edit or remove contributions and restrict participation when necessary to protect the community. Report conduct concerns privately to the repository owner through GitHub.
